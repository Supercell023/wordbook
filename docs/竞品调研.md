# 竞品调研

> **一句话结论**：头部产品赢在「内容量 + 记忆算法 + 社区留存」，输在付费墙、广告和复习债。词书的机会是反着来：词条做深、复习做轻、数据留在本地。

## 一、横向对比

| 产品 | 核心特色 | 优点 | 被吐槽点 | 启示 |
|---|---|---|---|---|
| 不背单词 | 150 万+原声例句、柯林斯、词根词缀 | 极简、英美音、语境强 | 卡片分栏要来回切、复习量大 | 内容深，但一屏读完 |
| 百词斩 | 图片背词、多题型 | 有趣、可离线 | 配图不贴切、变形词点不开、广告多 | 借题型，不碰图片 |
| 墨墨 | BMMS 算法、记忆矩阵 | 算法强、词条短 | 免费 600 词、内容少、UI 旧 | 算法简单可解释即可 |
| 扇贝 | 打卡 + 拼写/听写/复述 | 测试全、真题例句 | 变形词/形近词弱、付费项多 | 拼写自测值得做 |
| 欧路 | 词典级内容 + AI 短文 | 信息最全、复习可调 | 偏词典、学习闭环弱 | 全而不臃肿 |

## 二、分维度

**词条内容**：不背的柯林斯/词根/派生词要付费或酷币兑换；百词斩变形词「无扩展知识或链接」；墨墨信息少；扇贝详情页单薄；欧路最全但更像词典。我们把多义项+标准词性、英英释义、词形变化、近反义词、柯林斯星级、同族词可点做成免费同屏，方向对了。

**例句**：不背的原声+真题是护城河，版权也最贵；百词斩只有一句，真题影视弱；墨墨刻意不用更难词；扇贝按词书给真题；欧路有原声。我们用 Tatoeba 中英对照，覆盖 97.2%，离线可控，代价是偏口语、缺考试语境——对中学生够用。

**记忆算法**：墨墨 BMMS 靠点击和反应时长估掌握；不背用艾宾浩斯 +「连对 3 次」；扇贝靠打卡；欧路可自定义间隔。算法是黑箱卖点，K12 更需「看得懂、不欠债」：二元反馈 + 1/2/4/7/15/30 天，够用。

**复习机制**：不背被戏称「高利贷」，说明复习量必须可控。我们的原组复习、混合 20 词、生词本、拼写自测，原则是不制造复习债。

**激励/留存**：签到、虚拟币、组队/同桌/PK、班级排名是标配，代价是社交负担和广告。我们只做随机完成奖励 + 老师端进度，轻、离线、不打扰。

**UI/主题**：不背、欧路是第一梯队；墨墨偏旧；百词斩/扇贝广告多。我们宋体/Times New Roman、暗夜/跟随系统，5.6MB 单文件打开即背。

**离线与隐私**：百词斩能离线，其余多需联网；不背的 App Store 隐私标签显示会收集联系方式、设备标识等。我们全本地 localStorage，服务器只收昵称和进度，断网可背——这是最难被复制的差异。

**商业化**：不背卖权限，百词斩卖课+电商+广告，墨墨卖词数上限和发音，扇贝卖会员/课程/商城，欧路靠扩展词典。我们不商业化，也不打内容军备竞赛。

## 三、采纳 / 不采纳

**采纳（已做）**：多义项+标准词性、英英释义、词形变化、近反义词、柯林斯星级；同族词可点释义（补上百词斩「变形词不能点」的缺口）；词卡/搜索；随机完成奖励；宋体/Times New Roman、暗夜/跟随系统；1/2/4/7/15/30 天复习、原组/混合 20 词、生词本、拼写自测。

**不采纳**：版权图片、真人原声（贵、重，和单文件冲突）；词根词缀（质量参差，同族词+音节够用）；社区/课程/商城/广告（和「发给学生、无后端」冲突）；签到/虚拟币（要账号和服务端）；复杂算法参数与付费墙（柯林斯/词根收费正是痛点，我们反着做）。
