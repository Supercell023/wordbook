### 1.1 义项清洗规则（保守，优先不误删）

丢弃条件（满足任一）：

- 空串 / 纯空白；
- 既无汉字也无字母数字（纯标点、纯符号）；
- 长度 > 60 且不含中文（多为英文残句）；
- 形如 `见color` / `同colour` / `参见 go` 的纯索引项 —— 规则要求「索引目标是拉丁词」，
  所以 `见闻`、`同感` 这类中文词不会被删；
- 单独一个 `—` / `——` / `-` / `?`。

去重：同一词性内 `_norm_key`（去标点、空白、转小写）相同即视为重复，保留首次出现的那条。
顺序：不重排、不按词频排序（现有数据没有可靠的义项级词频，重排等于臆造）。

### 1.2 例句选优规则

硬规则（必须全部满足）：

- 包含目标词：主词 + `forms` 词形 + 常见屈折（`-s/-es/-ed/-ing/-er/-est/-'s`，含 `y→ies`、双写辅音）；
- 英文长度 20–150 字符；
- ≥ 4 个单词；
- 不含中文字符。

打分（越小越好）：句中生僻词更少 → 句子更短。

优先级与回退：

- `hand_examples.json` 是人工挑选：通过硬规则就保留（只修明显坏的句子）；
- 其余候选按分数选，同分保留先出现的；
- 没有合格候选时**保留原句**，不牺牲覆盖率；
- 回退保护：重选若让覆盖率下降超过 1 个百分点，整批退回原选择。

### 1.3 空词性回填（第 2 次构建）

`fill_pos` 的优先级是「数据自带词性 → 英英释义首个词性 → WordNet」，只填空组、不动已有词性：

- 上海中考 `sh_zk.json` 每条本来就有 `pos` 字段（`n.` / `adj.` / `prep.` …），之前完全没被使用；
- 上海高考 `sh_gk.json` 的 `zh` 自带词性前缀（如 `"n. 图书馆；藏书室"`），之前解析前被正则剥掉，
  等于主动丢词性；现在只保留词表里认识的缩写前缀，不认识的仍照旧剥掉，避免把 `abbr.` 之类当成义项；
- 对已存在 ECDICT 的词，只在「只有 1 组且词性为空」时用原表词性补，不改多词性词。

结果：空词性组 314 → **37**，首组空词性词 313 → **36**。

### 2.3 为什么例句只重选了 2 条

抽查数据发现：`examples.json` 与 `examples_new.json` 覆盖的词**几乎互补**（如 `abandon`
只在 examples.json，`about` 只在 examples_new.json），同一个词同时拥有多个合格候选的情况很少。
原句本身通过硬规则时，它的分数往往已经最优（更短、用词更常见），所以只有 2 条被换掉。
这是「没有更好的候选」，不是规则把好句过滤掉了：另有 246 条是候选全部不合格、
为避免覆盖率下降而保留的原句。

## 3. 已知问题（本轮没有解决）

1. **义项不排序**：仍按 ECDICT 原行顺序，同一词性内可能先出现生僻义；按使用频率排序需要义项级词频数据，本轮不引入。
2. **长义项只拦「无中文」的**：带中文的长义项（整句解释、括号注释）没有截断，只是被 `max_items=9` 限制条数。
3. **空词性未清零**：回填已加数据自带词性（上海两库）+ 英英释义 + WordNet 三层，从 314 组降到 37 组（36 个词首组为空），剩余多是专有名词、短语和 WordNet 无收录的词。
4. **例句覆盖率没有提高**：重选只在已有候选里挑，不生成新句；坏句为保覆盖率保留（246 条）。
5. **例句只看词形、不看词义**：多义词可能配到不对应义项的句子（例如 `bank` 的河岸义配到银行义的例句）。
6. **没有自然度评估**：评分只有生僻词数和长度，语法别扭但满足硬规则的句子仍可能胜出。
7. **FAMD 英文兜底仍是英文**：`英：` 前缀条目不提供中文，只保证点开有内容；共 12 条。
8. **未跑 tests**：按任务要求不执行 `tests/`，前端兼容性只靠 schema 自检 + 模板逐个字段核对（`w.fam || []`、`w.senses || []`、FAMD 缺失回退）。
9. **义项清洗只丢弃 22 条**：说明这批 ECDICT 释义本身的重复/噪声比预期少，不是清洗失效。

## 4. 下一步建议

1. 把 246 条「不合格但保留」的句子定向重写进 `data/hand_examples.json`（人工挑选优先级最高，构建会自动采用）。
2. 若可接受 ≤1 个百分点的覆盖率损失，可加开关直接删除不合格句，换更干净的例句区。
3. 例句与义项做语义对齐（候选句的 synset 与目标义项一致），可显著减少多义词错配；需要 WordNet 语义索引，成本中等。
4. 义项排序需要外部词频（COCA / SkELL 频率档），接入前建议保持现状。
5. 空词性可进一步用词形后缀统计弱推断（`-tion/-ment → n.`），但必须标注为推断值并先抽样验证误判率。
