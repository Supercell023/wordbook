# 部署指南

一台 1 核 2G 的云服务器（阿里云/腾讯云/华为云均可，Ubuntu 22.04 / Debian 12）足够一个老师带几十个学生。

## 一、准备

- 服务器有公网 IP，安全组放行 **22、80、443**（或只放行 8787）
- 一个域名（可选，但配 HTTPS 后学生用起来最稳，iOS 的 PWA 也要求 https）
- 把域名 A 记录指向服务器 IP

## 二、上传代码

```bash
# 在本地
scp -r wordbook root@服务器IP:/root/

# 或在服务器上
git clone https://github.com/<你的账号>/wordbook.git && cd wordbook
```

## 三、一键部署

```bash
cd wordbook/server
sudo bash deploy.sh --domain wb.example.com --password '换成你自己的密码'
```

脚本会：

1. 安装 Node.js 22（官方二进制，自动识别 x64/arm64）
2. 把服务端拷到 `/opt/wordbook`
3. 生成 `/etc/wordbook.env`（端口、老师账号密码、数据目录、大模型配置）
4. 注册 systemd 服务 `wordbook.service` 并开机自启
5. 如果给了 `--domain`，安装 Caddy 并自动签 HTTPS 证书，反代到 8787
6. 用 ufw 放行端口

常用参数：

```bash
bash deploy.sh                          # 默认 8787 端口，HTTP
bash deploy.sh --port 8080              # 换端口
bash deploy.sh --domain wb.example.com  # 自动 HTTPS
bash deploy.sh --password 'xxxx'        # 指定老师密码
```

重复执行是安全的：会保留 `data/`，只更新代码和服务配置。

## 四、验证

```bash
systemctl status wordbook
curl -s localhost:8787/api/health   # 应返回 {"ok":true}
journalctl -u wordbook -n 50        # 出问题看这里
```

浏览器打开：

- 学生端 `http://服务器IP:8787/`（或 https 域名）
- 老师端 `http://服务器IP:8787/admin`

老师账号默认 `teacher`，密码是部署时设置的那个；首次登录后在「激活码」里生成一批码发给学生。

## 五、接大模型（可选）

编辑 `/etc/wordbook.env`：

```ini
LLM_URL=https://api.deepseek.com/v1/chat/completions
LLM_KEY=sk-xxxx
LLM_MODEL=deepseek-chat
```

然后 `systemctl restart wordbook`。老师端点「AI 点评」时走大模型；没配或调用失败会自动退回本地规则分析，功能不受影响。

也可以换成任何 OpenAI 兼容接口（MIMO、通义、智谱等），只改 `LLM_URL` / `LLM_MODEL` 即可。

## 六、备份与迁移

所有数据都在一个文件里：

```bash
/opt/wordbook/data/db.json     # 学生、激活码、上传记录、任务、日志
/opt/wordbook/data/secret      # 令牌签名密钥（丢了所有人要重新登录/绑定）
```

定期备份这两个文件即可。换服务器时把 `data/` 整个拷过去，学生不用重新绑定。

## 七、常见问题

**学生打不开页面**
- 检查安全组/防火墙端口
- 用 `curl -I http://服务器IP:8787/` 确认服务在跑
- 学校网络可能屏蔽非标准端口，换 80/443 或配域名 https

**手机上提示「不安全」**
- 配了域名就用了 Caddy 的自动 HTTPS；没有域名就只能是 http，微信内打开可能提示风险，用「在浏览器打开」

**iOS 学生怎么装**
- 不能装 APK；Safari 打开 https 地址 → 分享 → 添加到主屏幕，即得到全屏 PWA
- 也可以给他们 Xcode 工程自行签名（需要 Mac），见 `ios/README.md`

**老师密码忘了**

```bash
sudo -i
cd /opt/wordbook
ADMIN_PASS='新密码' node server.js   # 启动一次会重置
# 或者改 /etc/wordbook.env 后 systemctl restart wordbook
```

**数据重置**

```bash
systemctl stop wordbook
rm -f /opt/wordbook/data/db.json
systemctl start wordbook   # 重新生成，老师密码回到初始值
```
