# 架构说明

## 一、总体形态

```
                 ┌──────────────────────────────┐
   data/*.json → │ tools/build.py               │ → dist/vocab.html（单文件）
   ecdict.csv    │ 词库 + 例句 + 音节 + 同族词   │      │
                 └──────────────────────────────┘      │
                                                       ├→ 浏览器直接打开（离线）
                                                       ├→ server/public（局域网/公网）
                                                       ├→ android/assets → APK
                                                       └→ ios/Resources/www → WKWebView
                                                                  │
                                                        学生端推送 → server.js → 老师端 admin.html
```

设计原则：**学习数据完全在本地**（localStorage），服务器只做「接收推送 + 老师查看」，学生断网也能正常背单词。

## 二、数据管线

`tools/build.py` 一次生成完整 HTML：

1. 读 `data/ecdict.csv`，按 `tag` 字段筛出 `zk/gk/cet4/cet6/ielts/toefl`
2. 合并 `sh_zk.json`（上海中考）、`sh_gk.json`（上海高考，scope=0）；上海词库需要的 STOP 词只补数据、不改变词库归属
3. 去停用词、按小写去重
4. 解析 `translation` → 多词性、多义项 `senses` + 专业义 `spec`；词性统一成 `n./v./vt./vi./adj./adv./prep./conj./pron./num./art./interj.`，缺词性时用英英释义首行或 WordNet 首 synset 推断；过滤「run 的过去式」这类词形注释行
5. 解析 `definition` → `defs`（最多 2 条、每条 ≤100 字符）
6. 解析 `exchange` → 词形变化 `forms`（过去式 / 过去分词 / 现在分词 / 第三人称 / 复数 / 比较级 / 最高级）
7. `collins` → 柯林斯星级 `stars`
8. WordNet → 近义词 `syn`（≤3）/ 反义词 `ant`（≤2）；同族词仍用后缀规则 + 派生链接，取词频最高的 3 个，词性写英文
9. 计算难度 `difficulty`：45% 层级 + 35% 词频 + 10% 词长 + 10% 义项组数
10. 音节：`pyphen` 切分，`ap·pear`
11. 例句：四级优先级合并（手工 > 补写 > 新语料 > Tatoeba/News-Commentary）
12. 第二遍扫 ECDICT，为同族词 / 近反义词生成 `FAMD` 短释义，供词卡点查
13. 把词表注入模板：`const RAW = __WORDS__; const FAMD = __FAMD__;`

每行 15 列：

```js
[w, ph, mask, diff, freq, ex, syl, fam, senses, spec, defs, forms, stars, syn, ant]
// w      单词                  ph    音标
// mask   词库位掩码（zk=1 gk=2 cet4=4 cet6=8 ielts=16 toefl=32 sh-zk=64 sh-gk=128）
// diff   难度 0~1             freq  词频排名（越小越常见）
// ex     [英文例句, 中文翻译]  syl   音节
// fam    [[同族词, 英文词性], ...]
// senses [[词性, [义项...]], ...]
// spec   [[专业领域, [义项...]], ...]
// defs   [[词性, 英英释义], ...]
// forms  [[中文标签, 词形], ...]
// stars  柯林斯星级 0~5
// syn    近义词数组            ant   反义词数组
```

`FAMD` 是 `{ 小写单词: 短中文释义 }`，只收同族词、近反义词，不重复存整份词表。

产物约 5.6MB、12,115 词；多义项 18,141 组 / 47,795 条，英英释义 11,986 词，词形 8,353 词，同族词 6,006 词，近义 8,688 / 反义 1,917，同族/近反义词简释义 11,297 条；空词性已从 314 组补到 37 组。浏览器解析一次后全部在内存里，翻页/抽词都是纯 JS。

## 三、应用（web/app.template.html）

单文件、零依赖、无构建步骤。核心是「一个状态 + 一组视图 + 一张动作表」：

```js
S = {
  v: 2, range, seq,                    // 版本、当前词库、组号
  learned: { word: {w,r,t,ok,due} },   // w=错次 r=复习次数 t=上次时间 ok=是否已掌握 due=下次复习时间
  groups:  [{ id, range, ts, ids, hist:[{ts,first,total,taps,dur,wrong}] }],
  actives: [session],                  // 未完成的组，最多 cfg.maxActive 个
  cur, lastDone, days, star, cfg, sync
}
```

- **视图**：`VIEWS.home / preview / quiz / done / book / group / starbook / spell / search`
- **动作**：`ACTIONS` 表 + `document` 上的 `data-act` 事件委托，所有按钮都走这一条路
- **会话**：`{kind, ids, queue, attempts, taps, fail, mastered, gno, peek, fb}`，kind 有 `learn/review/mix/star/due/spell/practice`
- **分组策略**：`stratPick` 按难度分层各取 1（均衡），`rampPick` 按组号递增难度（递进）；`formGroup` 先塞最多 40% 的回炉词
- **复习算法**：间隔重复，答对按 `[1,2,4,7,15,30]` 天递进，答错回到 1 天；错 2 次以上的词回炉优先进入下一组
- **持久化**：`localStorage['wordbook.v1']`，每次状态变更 `save()`；设置里可导出/导入 JSON 备份
- **语音**：优先 `window.AndroidTTS`（APK 注入的原生 TextToSpeech），否则 `speechSynthesis`；iOS 上先 `cancel()` 再延迟 40ms 播放
- **词卡 / 查词**：`openWordCard(key)` 支持数字 id、英文词和 `FAMD` 兜底；词卡分区展示义项、专业义、英英、词形、近反义、同族、例句和标签；同族词 / 近反义词可继续点开
- **主题**：`S.cfg.theme = auto|light|dark`，`applyTheme()` 同步 `html[data-theme]`、`color-scheme` 和 `meta[theme-color]`；系统切暗色时自动跟随
- **完成奖励**：达到每日目标或清空当天到期复习，`finish()` 记 `S.fxDay`，`celebrate()` 随机 canvas 撒花 / 星星 / 花瓣 / 烟花；jsdom 下自动跳过 canvas
- **PWA**：http(s) 且非原生 TTS 时注册 `sw.js`；`manifest.json`、`sw.js`、`icons/` 与 `vocab.html` 一起同步到四个端，断网可打开

## 四、班级服务器（server/server.js）

零依赖 Node（只用 `http`/`crypto`/`fs`），数据存 `data/db.json`，HMAC-SHA256 签名的无状态令牌。

学生接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/s/bind` | `{code,name,device}` 激活码换令牌，一码一人 |
| GET | `/api/s/me` | 当前学生信息 |
| POST | `/api/s/push` | `{hash,data}` 上传进度；hash 与上次相同返回 409（前端据此禁用按钮） |
| GET | `/api/s/inbox` | 老师的任务和留言 |
| POST | `/api/s/ack` | 标记已读 |

老师接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/t/login` | `{user,pass}` |
| GET | `/api/t/overview` | 班级概览：每组正确率、错词排行 |
| GET | `/api/t/student/:id` | 单个学生详情与上传历史 |
| GET/POST | `/api/t/codes` | 生成 / 查看激活码 |
| POST | `/api/t/assign` · `/api/t/message` | 布置任务 / 留言 |
| POST | `/api/t/analyze` | AI 点评（配置了 LLM 就走模型，否则本地规则） |

去重逻辑：学生端用 FNV-1a 把 `seq + learned + groups.hist` 算成指纹，指纹没变时按钮置灰；服务端再按 `hash` 兜底返回 409，双保险。

## 五、Android / iOS

- **Android**：普通 `WebView` 加载 `file:///android_asset/vocab.html`，通过 `addJavascriptInterface` 注入 `AndroidTTS`（`TextToSpeech` 包装），JS 侧检测到它就用原生发音；原生端按语言自动挑质量较高的本地音色，并支持 `setAccent/setRate`。网页端优先 `speechSynthesis` 的自然音色。高清模式用 `<audio>` 播有道词典音频，失败回退系统 TTS。打包不用 Gradle：`aapt` 编译资源 → `javac` → `d8` → `zipalign` → `apksigner`。
- **iOS**：`WKWebView` + `AVSpeechSynthesizer`，注入同名 `window.AndroidTTS` 桥接（`webkit.messageHandlers.tts`），所以网页不用区分平台；另外提供 PWA 作为免签名的方案。

## 六、测试

- `tests/test.js`：jsdom 加载 `dist/vocab.html`，模拟点击，检查 183 项行为（首页、答题、回队列、取消组、复习模式、生词本、每日目标、拼写、迁移、持久化、多义项、词卡、主题、搜索、奖励……）
- `tests/layout.js`：真实 Chromium 量各页面元素边界，检查手机宽度下没有横向溢出
- `tests/shot3.js`：截图，用于人工/视觉检查

## 七、工程与分发

- **构建数据**：`tools/fetch_data.sh` 从 skywind3000/ECDICT 下载约 66MB 的 `data/ecdict.csv`，先写 `.tmp`，校验 >50MB 与 `word,phonetic` 表头后原子替换；`--force` 强制重下，`ECDICT_URL` 可换镜像。
- **同步**：`build.sh sync` 把 `vocab.html`、`manifest.json`、`sw.js`、`icons/` 复制到 `dist/`、`server/public/`、`android/assets/`、`ios/Resources/www/` 四个端；`verify` 校验 manifest、PNG 真实尺寸和 PWA 标签。
- **缓存版本**：`web/sw.js` 的 `VERSION`（当前 `v4`）决定缓存名 `wordbook-v4`；改前端资源必须递增，`activate` 会删掉其余 `wordbook-*` 缓存。
- **更新提示**：新 SW 安装后 `skipWaiting()`；`activate` 在清理旧缓存、`clients.claim()` 之后，若确实存在旧版本缓存，向所有 window client 广播 `{type:'WB_UPDATED', version, cache}`。页面收到后提示「新版本」，也可回发 `{type:'SKIP_WAITING'}` 立即接管。导航网络优先、断网回落 `vocab.html`；`manifest` / `sw.js` 网络优先；其余静态资源缓存优先。
- **gzip**：`server/server.js` 在 `Accept-Encoding` 含 gzip 且资源为 HTML/JS/CSS/JSON/manifest/SVG、≥1KB 时压缩，附 `Vary: Accept-Encoding`；PNG/APK 不压缩。`sw.js` 仍返回 `Cache-Control: no-store`。
- **CI**：`.github/workflows/ci.yml` 在 push 到 `main`/`master`、Pull Request、手动触发时运行；Node 20 + Python 3.12，缓存 npm/pip，安装 pyphen/nltk 并下载 WordNet，`fetch_data.sh` → `build.py` → `sync` → `verify` → `node tests/test.js`；上传 `dist/vocab.html` 与已提交的 `android/wordbook.apk` 为 artifact，不安装 Android SDK。
- **release 签名**：`android/build.sh` 默认 debug 签名；`WORDBOOK_KEYSTORE` / `WORDBOOK_KEY_ALIAS` / `WORDBOOK_STOREPASS` / `WORDBOOK_KEYPASS` 四者齐全时改走 `apksigner` release，缺项回退 debug。版本号读 `AndroidManifest.xml` 的 `versionName`，产物 `android/wordbook-<版本>-<release|debug>.apk`，并保留 `android/wordbook.apk` 固定别名。
