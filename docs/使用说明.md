# 单词本 · 班级版 使用说明

## 一、给学生

1. 老师会给你 **服务器地址** 和 **你的激活码**（形如 `A1B2-C3D4`，一人一个，用一次就失效）。
2. 手机浏览器打开老师给的地址，或用老师发的 **App 安装包**。
3. 第一次用：右上角 ⚙ →「老师端同步」→ 填服务器地址、激活码、你的名字 → 绑定。
4. 背词都在手机本地，**不联网也能背**。
5. 背完一组后：首页会出现「↑ 有新的学习数据」→ 点它上传；成功后按钮变成「已上传 ✓」。
   - 没有新数据时按钮是灰的，不会重复上传。
   - 上传失败会提示原因，稍后重试即可。
6. 老师布置的任务和消息，会在首页状态条和「老师消息」里看到。

## 二、给老师

1. 浏览器打开 `https://你的域名/admin`（或 `http://服务器IP:8787/admin`）。
2. 用部署时设置的账号密码登录（默认 `teacher` + 初始密码）。
3. 「激活码」标签：生成一批，发给学生（一次性，绑定后作废）。
4. 「学生」标签：顶部看班级人数、今日已学、平均正确率、需关注人数，以及近 7 天学习量和班级高频错词；下面可以搜索、按最近上传/正确率/连续天数/复习积压排序，或筛选「今日未学 / 需关注 / 作业未读 / 正确率<60% / 未上传」。
5. 点学生卡看详情：7 天趋势、今日目标、连续天数、正确率、待复习、累计分钟、活跃天数、错词、收藏；还有练习构成、最近练习、作业回执和老师备注。备注会一起进 CSV。
6. 详情里可以「AI 点评」（服务器配了大模型才会走 AI，否则用本地规则分析），也能单独给这个学生布置任务。
7. 「布置」标签：下发任务或留言，学生下次同步时收到；列表能看到已读/未读、逾期人数，也能删除。
8. 右上角「导出 CSV」把当前学生名单（含今日、待复习、错词、作业、备注）导出给 Excel。

## 三、学生端功能

- **查词**：首页右上角 🔍，英文或中文都能搜（如 `book`、`预订`）；结果点开就是完整词卡。
- **词卡**：点熟悉页的词条、答题卡的「完整词卡」，或任意同族词 / 近反义词，都会打开词卡。
- **词义更全**：一个词的全部词性、多个义项、专业领域义、英英释义、词形变化（过去式 / 复数 / 比较级等）、柯林斯星级、近反义词。
- **同族词**：熟悉页展开后可看到同族词，每个词后面标英文词性（如 appearance `n.`）；点它直接查这个词。
- **今日复习**：每个词按自己的记忆难度安排间隔（答错缩短、答对逐步拉长，最长 180 天）；到期后首页出现「🔁 今日复习」，首页还会显示未来 7 天有多少词到期。
- **听音选义 / 例句填空**：首页「👂 听音选义」听发音四选一；「🕳️ 例句填空」把例句里的目标词挖空，选词补全。
- **错题本 / 薄弱词**：答错或拼错的词自动进错题本，按认词 / 听音 / 填空 / 拼写分类；「🩹 薄弱词」按错误次数和遗忘次数排序，可以只练这些词。
- **生词本**：答错的词自动收录（设置里可关），也能手动点 ☆；生词本可单独复习。
- **每日目标**：默认每天 20 词，可改成 10/20/30/50；首页显示连续打卡天数和最近 7 天柱状图。
- **完成奖励**：达到每日目标（或把当天到期复习清空）时，随机出现撒花 / 星星 / 花瓣 / 烟花，每天一次；可在设置里关闭。
- **外观**：设置 →「外观」可选 **跟随系统 / 浅色 / 暗夜**；首页标题旁的 ◐ 按钮可以快速切换。中文宋体、英文 Times New Roman。设置里还能调**字号（标准/大/特大）**和**高对比度**。
- **查词历史 / 词卡返回**：搜索页会记住最近查过的词；从同族词或近反义词一层层点进去后，词卡左上角的「‹」可以返回上一个词。
- **版本更新**：安装成 PWA 后，如果服务器上的版本更新，首页顶部会出现「新版本已就绪」，点一下就刷新。
- **拼写自测**：首页「⌨️ 拼写自测」，看中文写英文，20 词一局。
- **发音**：单词、例句旁的 🔊。设置 →「发音」可选 **高清（联网）/ 系统**，高清音色默认开启：单词发给有道，整句发给 Google 翻译语音；失败会自动回退系统 TTS；还能切**美音/英音**和**慢/标准/快**。APK 会自动挑手机里较自然的英文音色，网页版用浏览器语音。

## 四、部署一台服务器

见 README.md 的「一键部署」；最省事的做法：

```bash
sudo bash deploy.sh --domain wb.example.com --password '你的密码'
```

没有域名就用 `sudo bash deploy.sh`，然后在云服务器安全组里放行 8787 端口。

## 五、安装到主屏幕（PWA）

- **Android Chrome**：打开 `https://你的域名/vocab.html`，地址栏/菜单里会出现「安装应用」；安装后从桌面图标进入，全屏、离线可用。
- **iPhone Safari**：打开同一地址 → 分享 →「添加到主屏幕」。
- **前提**：必须是 **HTTPS**（或本机 `localhost`）。局域网 `http://192.168.x.x` 浏览器不允许安装；给服务器加 `--domain 你的域名` 即可自动申请证书。
- 构建 / 同步：`./build.sh all` 会生成 192/512/maskable/apple-touch 图标，并把 `manifest.json`、`sw.js`、`icons/` 同步到 `dist`、`server/public`、Android、iOS 四个目录。
- 想要原生 iOS 安装包：`ios/` 目录里有 Xcode 工程，需要 Mac + Xcode 签名。
