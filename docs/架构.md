# 架构说明

## 一、总体形态

```
                 ┌──────────────────────────────┐
   data/*.json → │ tools/build.py               │ → dist/vocab.html（单文件）
   ecdict.csv    │ 词库 + 例句 + 音节 + 同族词   │      │
                 └──────────────────────────────┘      │
                                                       ├→ 浏览器直接打开（离线）
                                                       ├→ server/public（局域网/公网）
                                                       ├→ android/assets → APK
                                                       └→ ios/Resources/www → WKWebView
                                                                  │
                                                        学生端推送 → server.js → 老师端 admin.html
```

设计原则：**学习数据完全在本地**（localStorage），服务器只做「接收推送 + 老师查看」，学生断网也能正常背单词。

## 二、数据管线

`tools/build.py` 一次生成完整 HTML：

1. 读 `data/ecdict.csv`，按 `tag` 字段筛出 `zk/gk/cet4/cet6/ielts/toefl`
2. 合并 `sh_zk.json`（上海中考）、`sh_gk.json`（上海高考，scope=0）
3. 去停用词、按小写去重，保留释义最短的写法
4. 计算难度 `difficulty`：45% 层级 + 35% 词频 + 10% 词长 + 10% 义项数
5. 音节：`pyphen` 切分，`ap·pear`
6. 同族词：后缀规则 + WordNet 派生链接（要求同前缀 ≥5 字母）+ 词表校验，取词频最高的 3 个
7. 例句：四级优先级合并（手工 > 补写 > 新语料 > Tatoeba/News-Commentary）
8. 把词表以 JSON 数组注入模板：`const RAW = __WORDS__`

每行格式：

```js
[w, ph, tr, mask, diff, freq, ex, syl, fam]
// w    单词            ph   音标
// tr   中文释义        mask 词库位掩码（zk=1 gk=2 cet4=4 cet6=8 ielts=16 toefl=32 sh-zk=64 sh-gk=128）
// diff 难度 0~1       freq 词频排名（越小越常见）
// ex   [英文例句, 中文翻译]  syl 音节  fam [[同族词, 词性], ...]
```

产物约 2.5MB、12,115 词，浏览器解析一次后全部在内存里，翻页/抽词都是纯 JS。

## 三、应用（web/app.template.html）

单文件、零依赖、无构建步骤。核心是「一个状态 + 一组视图 + 一张动作表」：

```js
S = {
  v: 2, range, seq,                    // 版本、当前词库、组号
  learned: { word: {w,r,t,ok,due} },   // w=错次 r=复习次数 t=上次时间 ok=是否已掌握 due=下次复习时间
  groups:  [{ id, range, ts, ids, hist:[{ts,first,total,taps,dur,wrong}] }],
  actives: [session],                  // 未完成的组，最多 cfg.maxActive 个
  cur, lastDone, days, star, cfg, sync
}
```

- **视图**：`VIEWS.home / preview / quiz / done / book / group / starbook / spell`
- **动作**：`ACTIONS` 表 + `document` 上的 `data-act` 事件委托，所有按钮都走这一条路
- **会话**：`{kind, ids, queue, attempts, taps, fail, mastered, gno, peek, fb}`，kind 有 `learn/review/mix/star/due/spell/practice`
- **分组策略**：`stratPick` 按难度分层各取 1（均衡），`rampPick` 按组号递增难度（递进）；`formGroup` 先塞最多 40% 的回炉词
- **复习算法**：间隔重复，答对按 `[1,2,4,7,15,30]` 天递进，答错回到 1 天；错 2 次以上的词回炉优先进入下一组
- **持久化**：`localStorage['wordbook.v1']`，每次状态变更 `save()`；设置里可导出/导入 JSON 备份
- **语音**：优先 `window.AndroidTTS`（APK 注入的原生 TextToSpeech），否则 `speechSynthesis`；iOS 上先 `cancel()` 再延迟 40ms 播放
- **PWA**：http(s) 环境下注册 `sw.js`，缓存页面与图标，断网可打开

## 四、班级服务器（server/server.js）

零依赖 Node（只用 `http`/`crypto`/`fs`），数据存 `data/db.json`，HMAC-SHA256 签名的无状态令牌。

学生接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/s/bind` | `{code,name,device}` 激活码换令牌，一码一人 |
| GET | `/api/s/me` | 当前学生信息 |
| POST | `/api/s/push` | `{hash,data}` 上传进度；hash 与上次相同返回 409（前端据此禁用按钮） |
| GET | `/api/s/inbox` | 老师的任务和留言 |
| POST | `/api/s/ack` | 标记已读 |

老师接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/t/login` | `{user,pass}` |
| GET | `/api/t/overview` | 班级概览：每组正确率、错词排行 |
| GET | `/api/t/student/:id` | 单个学生详情与上传历史 |
| GET/POST | `/api/t/codes` | 生成 / 查看激活码 |
| POST | `/api/t/assign` · `/api/t/message` | 布置任务 / 留言 |
| POST | `/api/t/analyze` | AI 点评（配置了 LLM 就走模型，否则本地规则） |

去重逻辑：学生端用 FNV-1a 把 `seq + learned + groups.hist` 算成指纹，指纹没变时按钮置灰；服务端再按 `hash` 兜底返回 409，双保险。

## 五、Android / iOS

- **Android**：普通 `WebView` 加载 `file:///android_asset/vocab.html`，通过 `addJavascriptInterface` 注入 `AndroidTTS`（`TextToSpeech` 包装），JS 侧检测到它就用原生发音。打包不用 Gradle：`aapt` 编译资源 → `javac` → `d8` → `zipalign` → `apksigner`。
- **iOS**：`WKWebView` + `AVSpeechSynthesizer`，注入同名 `window.AndroidTTS` 桥接（`webkit.messageHandlers.tts`），所以网页不用区分平台；另外提供 PWA 作为免签名的方案。

## 六、测试

- `tests/test.js`：jsdom 加载 `dist/vocab.html`，模拟点击，检查 123 项行为（首页、答题、回队列、取消组、复习模式、生词本、每日目标、拼写、迁移、持久化……）
- `tests/layout.js`：真实 Chromium 量各页面元素边界，检查手机宽度下没有横向溢出
- `tests/shot3.js`：截图，用于人工/视觉检查
