# 单词本 · 班级版 使用说明

## 一、给学生

1. 老师会给你 **服务器地址** 和 **你的激活码**（形如 `A1B2-C3D4`，一人一个，用一次就失效）。
2. 手机浏览器打开老师给的地址，或用老师发的 **App 安装包**。
3. 第一次用：右上角 ⚙ →「老师端同步」→ 填服务器地址、激活码、你的名字 → 绑定。
4. 背词都在手机本地，**不联网也能背**。
5. 背完一组后：首页会出现「↑ 有新的学习数据」→ 点它上传；成功后按钮变成「已上传 ✓」。
   - 没有新数据时按钮是灰的，不会重复上传。
   - 上传失败会提示原因，稍后重试即可。
6. 老师布置的任务和消息，会在首页状态条和「老师消息」里看到。

## 二、给老师

1. 浏览器打开 `https://你的域名/admin`（或 `http://服务器IP:8787/admin`）。
2. 用部署时设置的账号密码登录（默认 `teacher` + 初始密码）。
3. 「激活码」标签：生成一批，发给学生（一次性，绑定后作废）。
4. 「学生」标签：看谁学过、学了几组、首次掌握率、错词排行；点「详情」看走势和每次上传记录。
5. 详情里可以「AI 点评」（服务器配了大模型才会走 AI，否则用本地规则分析）。
6. 「布置」标签：下发任务或留言，学生下次同步时收到。

## 三、学生端新功能（v3）

- **今日复习**：学过的词按 1/2/4/7/15/30 天自动安排复习，到期后首页出现「🔁 今日复习」。
- **生词本**：答错的词自动收录（设置里可关），也能手动点 ☆；生词本可单独复习。
- **每日目标**：默认每天 20 词，可在设置里改成 10/20/30/50；首页显示连续打卡天数。
- **拼写自测**：首页「⌨️ 拼写自测」，看中文写英文，20 词一局。
- **单词页**：音节划分（ap·pear）、同族词（appear → appearance 名）、中英例句、系统发音。

## 四、部署一台服务器

见 README.md 的「一键部署」；最省事的做法：

```bash
sudo bash deploy.sh --domain wb.example.com --password '你的密码'
```

没有域名就用 `sudo bash deploy.sh`，然后在云服务器安全组里放行 8787 端口。

## 五、iPhone（iOS）

- **不用安装**：Safari 打开 `https://你的域名/student.html` → 分享 → 添加到主屏幕，全屏使用，断网可背（需 https）。
- 服务器要配 HTTPS：部署时加 `--domain 你的域名`，脚本会装 Caddy 自动申请证书。
- 想要原生安装包：`ios/` 目录里有 Xcode 工程源码与说明，需要 Mac + Xcode 签名（免费账号 7 天，付费账号 1 年/TestFlight）。
